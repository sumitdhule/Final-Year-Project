# 👨‍🎓 Face Recognition Based Smart Attendance System  

A **Face Recognition Based Smart Attendance System** developed as a final year project for **B.E. Information Technology (2023–2024)** at **Prof. Ram Meghe Institute of Technology & Research, Badnera**.  

This project uses **Computer Vision and Machine Learning** to automate attendance marking by recognizing student faces in real time.  

---

## ✨ Features  
- 📷 Face detection using **OpenCV**  
- 🧠 Face recognition using **CNN (Convolutional Neural Network)** for feature extraction  
- 🎯 Classification with **SVM (Support Vector Machine)**  
- 🔐 Attendance marking stored securely in **Firebase**  
- 🌐 User-friendly front-end using **HTML & CSS**  
- 📊 Real-time attendance monitoring  

---

## 🛠️ Technologies Used  
- **Programming Language:** Python  
- **Libraries & Tools:** OpenCV, NumPy, TensorFlow/Keras, Scikit-learn  
- **Frontend:** HTML, CSS  
- **Database:** Firebase Realtime Database  
- **ML Algorithms:** CNN for feature extraction, SVM for classification  
- **IDE:**  VS Code

## ⚙️ Setup & Installation  

### 1. Clone the repository  
```bash
git clone https://github.com/sumitdhule/Final-Year-Project.git
cd Final-Year-Project
```

### 2. Install required dependencies  
```bash
pip install -r requirements.txt
```

### 3. Configure Firebase  
- Create a Firebase project.  
- Add **Firebase credentials** in your project (JSON file).  
- Update the Firebase path in `app.py`.  

### 4. Run the Application  
```bash
python app.py
```
